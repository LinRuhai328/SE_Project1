# 先看这6件事

文档已有框架，这轮重点是把规则说清。课程要求“有这个功能”，不等于具体处理方式已经谈定。

| 没说清的事 | 用一个例子理解 | 这轮要定什么 |
|---|---|---|
| 谁有权做什么 | 如果个人账本里只有你一个人，还需要别人来审核吗？ | 定清三类角色，以及个人账本是否走同一套审核。 |
| 一笔账什么时候算数 | 100元已经审核，后来发现应是120元，能直接改掉吗？ | 定清审核前后怎样改、撤回、作废和更正。 |
| 钱应该算到谁头上 | 你花了30元，我帮你录进去，成员统计算谁的？ | 定清是否允许代记，以及统计按谁归属。 |
| 结算到底结什么 | 这个月结算后发现漏了一笔30元，旧结果怎么办？ | 定清结算结果、结算后改账和历史保留方式。 |
| 第一版做到哪一步 | AI、截图、省钱目标、微信提醒，哪些现在就必须有？ | 定清首版范围；储钱罐是否只做虚拟记录。 |
| 截图怎样避免多记或漏记 | 截图10笔中8笔已记过，重传后这次该入几笔？ | 若首版做截图，定清重复提示、人工确认及失败重传。 |

先聊角色、记账流程、成员统计和结算。再逐项选辅助功能，最后补验收条件。

“17条已确认”目前只是初稿标签计数，不能直接当成最终数量已经达标。本文只帮助阅读与讨论，尚未记录任何新的甲方答复。
