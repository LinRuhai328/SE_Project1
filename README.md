目前已表达的三项选择：预约面交、预约成功即占用、卖家接受后开放双方联系方式。

下一轮重点作出的业务决定：

1. 卖家接受前后，买家和卖家分别能否取消，是否要说明原因或征得对方同意。
2. 卖家长期不处理预约、双方爽约时，是否设期限及释放条件。
3. 谁确认成交；实际交付后对方不确认时，平台处理到什么程度。
4. 取消、完成、违规下架以后，是否仍允许继续查询联系方式。

这些尚未作出的选择可与工程师讨论后确定；不把讨论稿中的建议直接当作已经同意。当前收到的是你与 AI 的二手准备讨论，尚未收到你与对方工程师的二手交易正式访谈原文。

## 你做多人记账乙方时

目标是把实际访谈与课程要求整理成可追溯、可验收的需求，再审查 AI 的整理结果。已经收到的原文可作为首轮沟通材料，保留原话和时间戳。

原文已提出共享账本、手动录入、截图导入与去重、成员权限、历史开销查询，以及 AI 和省钱目标等辅助设想。下一步应特别检查：

1. **角色：**目前主要是管理员和普通成员，需要明确第三类实际不同的权限角色。
2. **记录生命周期：**新增、提交、审核、驳回、撤回、作废分别由谁操作；已审核记录如何更正。
3. **结算：**结算意味着什么，结算后怎样补录或更正，以及统计怎样保持一致。
4. **导入和并发：**重复截图、两笔同额真实消费、重复提交、修改与审核冲突怎样处理。
5. **范围：**储钱罐是虚拟目标还是真实资金，AI 与通知渠道哪些属于第一版。
6. **质量：**性能、安全、可靠性分别在什么条件下、以什么结果验收。

可直接用于后续沟通的开场：

> 上次你把共享记账作为核心，AI 和储钱罐作为辅助。我想把一笔共享账的规则问完整：从新增到审核、统计和结算，分别由谁处理，哪些时候还允许修改或撤回？

完整来源及分支问题见[记账访谈整理与补充提纲](docs/多人记账访谈整理与补充提纲.md)。
